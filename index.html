1. General information

Focus Lock helps users reduce distractions by blocking selected apps during focus sessions. The app works mainly locally on the user's device.

2. Data processed by the app

Focus Lock may locally store: blocking profiles, lists of apps in profiles, schedules, the active session, session history, focus time, number of attempts to open blocked apps, names of apps attempted during a session, language and appearance settings, Premium settings, PIN and recovery code, and a JSON backup if the user manually exports it.

The app does not store message content, passwords, conversations, photos, contacts, or content displayed inside other apps.

3. Usage access

Focus Lock uses Android Usage Access permission to detect which app is currently open. This is needed to check whether the user is trying to open an app on the blocked apps list. This information is used only for blocking, session statistics, and blocked attempt history.

4. Accessibility service

Focus Lock uses Android Accessibility Service to detect when selected blocked apps are opened during an active session and to return the user to the home screen. The Accessibility Service may also help provide additional Premium session protection, for example by making it harder to access selected settings screens that could be used to disable the block.

Focus Lock does not use the Accessibility Service to read private messages, passwords, payment data, or text entered in other apps.

5. Notifications and foreground service

During an active session, Focus Lock may show a notification with session status, remaining time, number of attempts, and the selected profile. The foreground service is used only during an active session or for functions needed to start a scheduled session.

6. Schedules and exact alarms

The schedule feature may use Android system alarms to start a session at the selected time. On newer Android versions, the user may be asked to allow exact alarms. Alarms are used only to start scheduled Focus Lock sessions.

7. PIN and recovery code

The Premium version may allow the user to set a PIN that protects profiles, schedules, settings, and ending an active session early. When the PIN is created, the app may generate a recovery code. The recovery code is used to regain access if the user forgets the PIN. The user should store the recovery code outside the phone.

The PIN is not stored in plain text. The app stores a technical hash needed for verification.

8. Backup

The user can export settings to a JSON file. The backup may include profiles, apps in profiles, schedules, goals, theme, language, and session history. The PIN and Premium status are not exported. The backup file is created only after a user action.

9. Premium and payments

Focus Lock Premium may be offered as a one-time in-app purchase handled by Google Play Billing. Payments are processed by Google Play. Focus Lock does not store the user's payment card details or billing information.

The Premium purchase is linked to the Google account used in Google Play. After reinstalling the app or changing the phone, the user can restore the purchase if the same Google account is used.

10. Whether data is sent to a server

Focus Lock does not send profiles, session history, blocked app lists, blocked attempts, PIN, or recovery code to the developer's own server. Data is stored locally on the user's device, except for information handled by Google Play for Premium payments.

11. Data sharing

Focus Lock does not sell user data and does not share local session data, profiles, or app lists with third parties. Data related to Premium payment is handled by Google Play according to Google's policies.

12. Data deletion

The user can delete app data by deleting profiles and history in the app, clearing app data in Android settings, or uninstalling the app. Uninstalling the app removes local app data from the device. The Premium purchase remains linked to the Google account and can be restored through Google Play.

13. Security

Focus Lock stores data locally on the user's device. Access to this data depends on Android system security and the security of the device itself. The user should protect the phone with a screen lock and should not share the recovery code with unauthorized persons.

14. Children and minors

Focus Lock may be used by a parent or guardian to make it harder for a child to disable the block during an active session. However, the app is not a remote parental control system and does not send reports to a parent over the internet.

15. Changes to this Privacy Policy

This Privacy Policy may be updated if the app changes, Premium features change, Google Play requirements change, or legal requirements change.
